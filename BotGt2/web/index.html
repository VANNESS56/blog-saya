Pertanyaan Umum (FAQ)
Bagaimana cara mengaktifkan bot WhatsApp?
Untuk mengaktifkan bot WhatsApp, ikuti langkah-langkah berikut:
  1. Klik tombol "Start" pada panel Kontrol Bot di atas.
  2. Masukkan nomor WhatsApp yang ingin digunakan sebagai bot.
  3. Buka aplikasi WhatsApp di HP Anda, lalu masuk ke Linked Devices > Link a Device.
  4. Masukkan kode pairing 8 digit yang muncul di dashboard ini.
  5. Tunggu hingga status berubah menjadi "Connected".
Bagaimana kalau bot tiba-tiba offline?
Jika bot tiba-tiba offline, pastikan:
  1. Koneksi internet server / VPS Anda stabil.
  2. Cek apakah sesi WhatsApp masih terhubung di HP (Linked Devices).
  3. Klik "Hapus Sesi" lalu "Start" ulang untuk membuat koneksi baru.
  4. Periksa Log Terminal untuk melihat pesan error yang muncul.
Apakah saya bisa pakai nomor WhatsApp utama untuk bot?
Bisa, tapi tidak disarankan. Menggunakan nomor utama berisiko terkena ban dari WhatsApp jika bot melakukan spam atau aktivitas yang melanggar ketentuan layanan. Kami merekomendasikan menggunakan nomor WhatsApp terpisah khusus untuk bot.

FAQ's

Pertanyaan yang sering ditanyakan seputar penggunaan Kucai Bot.

Bagaimana cara mengaktifkan bot WhatsApp?
Untuk mengaktifkan bot WhatsApp, ikuti langkah berikut:
  1. Buka halaman Dashboard lalu klik panel Kontrol Bot.
  2. Masukkan nomor WhatsApp yang ingin digunakan sebagai bot.
  3. Buka aplikasi WhatsApp di HP, lalu masuk ke Linked Devices > Link a Device.
  4. Masukkan kode pairing 8 digit yang muncul di dashboard.
  5. Tunggu hingga status berubah menjadi "Connected".
Bagaimana kalau bot tiba-tiba offline?
Jika bot tiba-tiba offline, pastikan:
  1. Koneksi internet server / VPS kamu stabil.
  2. Cek apakah sesi WhatsApp masih terhubung di HP (Linked Devices).
  3. Klik "Hapus Sesi" lalu "Start" ulang untuk membuat koneksi baru.
  4. Periksa Log Terminal untuk melihat pesan error yang muncul.
Apakah saya bisa pakai nomor WhatsApp utama untuk bot?
Bisa, tapi tidak disarankan. Menggunakan nomor utama berisiko terkena ban dari WhatsApp jika bot melakukan spam atau aktivitas yang melanggar ketentuan layanan. Kami merekomendasikan menggunakan nomor WhatsApp terpisah khusus untuk bot.
Bagaimana cara menambahkan trigger / auto-reply?
  1. Buka halaman Command di sidebar.
  2. Klik tombol "Add Trigger".
  3. Isi Kata Kunci, pilih Mode Cocok (Exact / Contains), lalu tulis Teks Balasan.
  4. Klik Tambah Trigger untuk menyimpan.
Bot akan otomatis membalas pesan yang cocok dengan kata kunci yang kamu atur.
Apa itu prefix dan bagaimana cara mengubahnya?
Prefix adalah karakter pemicu di depan perintah agar bot tahu kamu sedang memanggil bot. Contoh: jika prefix-nya #, maka user harus mengetik #menu untuk memanggil menu.

Untuk mengubahnya, buka halaman Config > bagian Prefix Perintah. Kamu bisa mengatur mode Multi (banyak prefix), Single, atau Tanpa Prefix.
Bagaimana cara mengatur jadwal kerja bot?
  1. Buka halaman Config.
  2. Scroll ke bagian Jadwal Kerja.
  3. Aktifkan toggle "Aktifkan Jadwal Kerja".
  4. Atur jam mulai, jam selesai, dan pilih hari kerja.
  5. Isi Pesan Offline yang akan dikirim di luar jadwal.
  6. Klik Simpan Config.
Bot akan otomatis mengirim pesan offline dan berhenti merespon di luar jadwal yang ditentukan.
Apa itu variable di Menu Bot dan bagaimana cara pakainya?
Variable adalah placeholder teks dinamis yang akan diganti otomatis saat pesan dikirim. Contoh:
  • {pushname} — Diganti dengan nama pengirim pesan.
  • {namebot} — Diganti dengan nama bot.
  • {ucapan} — Diganti dengan salam waktu (Pagi/Siang/Sore/Malam).
Gunakan variable di halaman Menu dengan cara mengetik langsung atau klik dari panel Variable yang Tersedia.
Apakah data bot saya aman?
Ya. Semua data tersimpan secara lokal di database SQLite di server/VPS kamu sendiri. Kucai Bot tidak mengirim data apapun ke server pihak ketiga. Sesi WhatsApp dan konfigurasi bot hanya bisa diakses oleh admin yang login ke dashboard.
